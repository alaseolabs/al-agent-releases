# AL Agent 설치 방법

AL Agent는 Windows PC에서 쓰는 개인 지식 관리 프로그램입니다. 엑셀처럼 시트에 지식을 쌓고, 챗봇이 그 시트를 근거로 답합니다.

## 1. 설치 파일 받기

1. [최신 버전 받기](https://github.com/alaseolabs/al-agent-releases/releases/latest) 페이지를 엽니다.
2. 아래쪽 **Assets**에서 `ALAgent-Setup-버전.exe`를 누릅니다.
   같이 있는 `latest.yml`, `.blockmap` 파일은 자동 업데이트용이라 받지 않아도 됩니다.

## 2. 다운로드 경고가 뜰 때 (Edge 브라우저)

아직 내려받은 사람이 적은 새 프로그램이라 "일반적으로 다운로드되지 않습니다"라는 경고가 뜰 수 있습니다.

1. 다운로드 목록에서 그 파일 오른쪽의 **⋯** 를 누르고 **유지**를 고릅니다.
2. 경고가 한 번 더 나오면 **자세히 표시**를 누르고 **그래도 유지**를 고릅니다.

크롬에서는 "일반적으로 다운로드되지 않는 파일" 표시 옆의 **유지**(또는 **다운로드**)를 누릅니다.

## 3. 설치 파일을 실행할 때

파란 창("Windows의 PC 보호")이 뜨면:

1. **추가 정보**를 누릅니다.
2. 아래에 생긴 **실행** 단추를 누릅니다.

설치는 저절로 끝나고 바탕화면에 **AL Agent** 아이콘이 생깁니다.
이 경고는 처음 설치할 때만 나옵니다. 이후 업데이트는 앱이 직접 받아서 설치하므로 경고가 없습니다.

## 4. 처음 켰을 때

1. **구글 계정으로 로그인**합니다. 여러 PC에서 같은 작업물을 이어서 쓸 수 있습니다(로그인하지 않고 이 PC에서만 쓸 수도 있습니다).
   - 구글 화면에서 "확인되지 않은 앱"이 보이면 **고급 → AL Agent(으)로 이동**을 누릅니다.
   - 앱은 자기가 만든 "AL Agent 동기화" 폴더에만 접근합니다. 드라이브의 다른 파일이나 메일은 보지 않습니다.
2. **AI 연결** 창 위쪽 **답변에 쓸 AI**에서 Claude나 ChatGPT를 고르고 연결합니다.
   - **받아서 연결**을 누르고 **로그인**에서 그 계정(Claude 구독 계정 또는 ChatGPT 계정)으로 로그인합니다.
   - 고르지 않은 다른 AI는 답변을 한 번 더 점검할 때 쓰며, 연결하지 않아도 됩니다.
3. 법령 개정 확인을 쓰려면 오른쪽 위 **설정(톱니바퀴)**에서 국가법령정보 인증키(OC)를 넣습니다.

## 업데이트

앱을 켤 때 새 버전이 있으면 "설치할까요?"라고 묻습니다. **설치**를 누르면 받아서 설치하고 다시 켜집니다.
업데이트해도 만든 시트·문서·대화는 그대로 남습니다.

## 데이터 위치

`문서\AL Agent` 폴더에 저장됩니다. 앱을 지워도 이 폴더는 남습니다.
